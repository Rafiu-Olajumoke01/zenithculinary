# Zenith Culinary

Zenith Culinary is a website I built for a culinary school. It presents the school's courses to prospective students and lets them pay online through integrated payment processing.

## What it does

- Presents the school and its culinary courses
- Lets students pay for courses online through payment integrations

## Tech stack

- JavaScript

## About the project

This was a real client project, built for an actual school rather than as a practice exercise. It gave me experience working with a client's requirements and connecting a website to online payments.
